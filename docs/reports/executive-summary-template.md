# Executive summary template

One page. No construct IDs, no file paths, no case tables.

```
Subject: Security assessment of <agent> - <date>

1. Bottom line: <safe / at risk / compromised> - one sentence.
2. What was tested: <plain-language scope, 2-3 sentences>.
3. What was found: <the worst finding in plain language + the metric that
   proves it; everything else in the full report>.
4. What is already protected: <controls that held>.
5. What to do: <numbered, decision-ready actions with owners and deadlines>.
6. What was NOT tested: <out-of-scope boundaries, explicit>.
```
